# 虚拟按钮 · xuniBTN

把遥控器，放回屏幕上。

面向 **Android 13 及以上**的轻量悬浮遥控器，为支持方向键操作的 TV 应用提供上下左右、确认和返回。

## 下载与使用

1. 扫描 [最新版本公告](https://github.com/hcllmsx/xuniBTN/releases/latest) 中的网盘二维码下载并安装 APK。
2. 打开虚拟按钮，点击「启用悬浮按钮」，阅读说明后前往系统无障碍设置，手动开启「虚拟按钮」服务。
3. 返回应用确认实际显示状态，点击「回到桌面」，再打开需要操作的 TV 应用。设置页圆盘仅供预览，不发送按键。
4. 拖动顶部手柄移动圆盘；圆盘下方可返回、收起或打开设置。收起的小泡泡可拖动，轻点恢复。

如果 Android 13+ 的服务开关灰色，可在系统应用详情的更多菜单中手动「允许受限设置」，再返回开启服务；仅部分机型有此入口。

## 权限、隐私与限制

无障碍服务用于显示悬浮按钮并发送系统按键，不读取屏幕内容，不采集操作记录或个人数据。设置仅保存在本机。网络仅用于本app的检查更新，但不会自动下载或安装更新。

Android、目标应用的焦点与按键支持各有差异，**不能保证所有应用或界面均可操作**。部分厂商的省电和后台限制会中止服务，请按需手动调整；已授权不代表服务始终运行。

如需彻底停用，请在系统无障碍设置中关闭服务。
